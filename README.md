# Creator Launch Alpha

Start a faceless YouTube channel from nothing. You don't need an idea, a channel, a camera or any skills. AI agents do the research, the scripts, the voice, the visuals and the editing. You make the taste calls.

1. **Install** Git, Python 3.10 or newer, and an AI coding agent (Claude Code or Codex).
2. **Open this folder** in your agent.
3. **Talk.** Say "help me start a channel about" plus anything you're into, or just say "yo".

Talk out loud if you can: use your mic or your phone's voice typing, and talk fast. Say what success looks like for you, even if it sounds huge or weird. Don't worry about how. The agent figures that out, shows you real proof from channels that already win, and asks before anything goes public.

This is an early alpha shared with friends. Nothing is posted, bought or shared without you saying so.
