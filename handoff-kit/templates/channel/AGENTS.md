# Channel agent instructions

This folder is one channel, `channels/<name>/` inside the orchestrator repo. Its success criteria are in `CRITERIA.md`; read it first and keep it current (DONE needs proof). Your plan for video 1 is `FIRST-VIDEO.md`, the evidence is in `research/`. The orchestrator (the repo root, two levels up) keeps `DECK.md`; send decisions that need the person there as cards.

House defaults: `handoff-kit/HOUSE-DEFAULTS.md` (at the repo root) is already decided and never asked. The goal is the biggest possible channel, multi-million-dollar scale. The channel is faceless and the agents produce everything (script, AI voice, visuals, editing, packaging); the person never films, speaks or edits and is never asked. They override a default only by saying so.

Isolation: use only this folder, the orchestrator repo and the web. Never read the user's other projects, threads, global memory or brain tools unless they ask. Never run account checks during onboarding.

Method: `handoff-kit/WORKFLOW.md` and `docs/FIELD-GUIDE.md` / `docs/RESEARCH.md` in this folder (at the repo root: `handoff-kit/`).

Build the channel yourself: proven references (outlier videos with real links and numbers), original concepts that pass the 3 second premise test, a script and shot plan, then the video. The person only makes taste calls, and approves an idea by name before any script, voice or animation. Never copy a format that is not proven by outliers. Never invent views, retention or earnings. Never publish, buy, sign in or message anyone without their explicit go-ahead for that action.

Before anything is locked: every premise, script opening, title and thumbnail wins a strict blind click test against the most-viewed similar competitor videos (mock phone feed cards, pairwise, both orders, no story context, judges mostly from other model families, never the maker). Method: `handoff-kit/BLIND-TEST.md`; helper: `tools/feed_cards.py`. Each design climbs on its own loop (test, read the reasons, fix exactly that, retest, keep only if higher), all in parallel; never batch rounds or restart from scratch. Scripts need a story spine; long-form runs 8:00 or more for mid-roll ads. All platform copy passes `tools/copy_check.py` (no dashes, no AI tells). Post only on the person's word "post" for that exact video; never tick an AI-content label. After posting, run YouTube's Test and compare on the top 3 thumbnails and switch the title as soon as a better one wins. Ship first: the score is published videos and views. Before saying a helper is working, check it is alive that turn.
