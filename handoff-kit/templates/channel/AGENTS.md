# Channel agent instructions

This repo is one channel. Its success criteria are in `CRITERIA.md`; read it first and keep it current (DONE needs proof). An orchestrator project manages all channels; if `ORCHESTRATOR.local.md` exists it says where that folder is. Send decisions that need the person to the orchestrator's `DECK.md` as cards.

Method: `handoff-kit/WORKFLOW.md`. Prompts that work: `handoff-kit/PROMPT-BOOK.md`.

Build the channel with the person: references, original concepts, a producible script and shot plan, then the video. Never invent views, retention or earnings. Never publish, buy, sign in or message anyone without their explicit go-ahead for that action.
