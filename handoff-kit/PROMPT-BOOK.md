# Prompt book

The funniest, most surprising prompts that got real work done, each with what it got done and why it works.

**Status: placeholder.** The curated prompts are being mined from real sessions and will land here. Until then, three habits that carry most of them:

1. **Yap first.** Start a project by saying everything in your head, messy, with the weird goals in. Then say: "Turn this into success criteria I can check, and tell me which ones are weak."
2. **Demand proof.** "Show me. A file I can open, a screenshot of the real result, or say 'not verified yet'."
3. **Kill weak ideas fast.** "Attack this list like a bored viewer who has seen everything. Keep only what survives, and say why the rest died."

Sections that will be filled: start a project by yapping, set success criteria, correct an agent, demand proof, kill a weak idea, the funny ones.
